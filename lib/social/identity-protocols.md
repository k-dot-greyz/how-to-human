# Identity Protocols

Scripts for social-network identity and authentication. Not a ranking of other people's firmware.

## 1. Passive IFF system (skins, style, tattoos)

**Purpose:** Broadcast a non-verbal compatibility ping so the right nodes find you faster, and you spend less CPU negotiating basics with every stranger on the network.

**Mechanism:** Customizing the chassis — clothes, tattoos, hair, hardware — is a visual checksum. People running similar firmware recognize the signal. People who are not a fit can skip the expensive handshake. That is a filter for *fit*, not a moral judgment of default configurations. You still choose when to open a port.

## 2. Documented API

Say what you mean. Be consistent. Have error handling (apologize, patch, retry). An undocumented API returns `500` every time someone tries to connect. Full network stack: [docs/core-guide.md](../../docs/core-guide.md) Module 04.
