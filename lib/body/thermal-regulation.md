# Thermal Regulation

Scripts for managing the system's thermal state.

## 1. `force_coolant_reroute.sh` (hot foot soak)

**Purpose:** Patch a common hardware bug where coolant (blood) is poorly distributed — cold peripherals (feet), overclocked CPU (anxious mind). Forces a thermal cycle that draws load off the CPU.

**Execution:**

1. Basin large enough for both feet.
2. Hot water — stress test, not a meltdown.
3. Submerge.
4. The system reroutes thermal resources to the peripherals. CPU load often drops with it.
5. Hold 10–15 minutes. Optional: Epsom salts (magnesium sulfate) if you are patching a magnesium gap.
