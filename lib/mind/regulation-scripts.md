# Regulation Scripts

Emergency scripts for runaway processes and system instability.

## 1. Hard reboot (`cold_shock.sh`)

**Purpose:** Non-graceful reboot when user-space is hung (circular thoughts). Holding the power button. Terminates the loop and reloads the kernel.

**Execution:**

1. Sudden intense cold: cold shower, or face in ice water.
2. Mammalian dive reflex drops heart rate and reroutes resources to core functions.
3. Jarring. Extremely effective. Use when standard debugging fails.

## 2. Sync system clock (`box_breathing.sh`)

**Purpose:** Manual clock regulation when the cycle is too fast (panic) or erratic (anxiety).

**Execution:**

1. `inhale(4)`
2. `hold(4)`
3. `exhale(4)`
4. `wait(4)`
5. `loop` for 1–2 minutes. The four-sided box gives the CPU a boring, predictable clock.

## 3. Poll external sensors (`54321_grounding.sh`)

**Purpose:** Stop a runaway internal loop (anxiety, flashbacks, dissociation) and re-read the attached peripherals.

**Execution:**

1. Optical: name **5** things you can see.
2. Tactile: name **4** things you can feel.
3. Audio: name **3** things you can hear.
4. Olfactory: name **2** things you can smell.
5. Gustatory: name **1** thing you can taste.

Sequential polling steals resources back from the error state and returns them to present reality.
