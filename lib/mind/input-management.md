# Input Management

Scripts for how data hits the system.

## 1. `pipe_to_audio.sh` (pipe text to audio)

**Purpose:** Offload text from optical sensors to the audio unit. Frees visual focus for moving through space or doing chores. Lowers the CPU cost of decoding written language.

**Execution:**

1. Identify low-to-medium density text (newsletters, docs, articles).
2. Use a TTS / Read Aloud function.
3. Pipe to headphones or speakers.
4. Parallel processing without melting the eyeballs.

## 2. Unplug the noise floor

Your brain has a limited patch bay. Every podcast, alert, song, and conversation is a cable. Plug everything in and you get white noise. Curate inputs. Improve signal-to-noise. The full mixing-desk model lives in [docs/core-guide.md](../../docs/core-guide.md) Module 02.
