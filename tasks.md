# how-to-human overhaul

## Main use case (MVP UX)

**As** a neuro-spicy human who lands on this repo or on greyZ's GitHub profile,
**I want** to know in three seconds what this is, grab the highest-ROI protocol, and find a donate path without being panhandled,
**so that** I actually use the manual instead of bouncing off a crypto splash page.

### Guiding flow

1. **Hook** (visual banner + one-liner + ASCII boot splash)
2. **Quick Start** — Core Guide, panic scripts, sleep tonight, one habit branch
3. **Library** — `lib/body`, `lib/mind`, `lib/social` (one path per protocol)
4. **Manifesto** — linked, not pasted four times
5. **Fuel** — collapsed `<details>` + `.github/FUNDING.yml` + `docs/donate.md` (BTC/SOL only; no ETH placeholder; no base64 QRs)

### Profile (copy into `k-dot-greyz/k-dot-greyz`)

Same rules: eye-catching hook first, featured work second, donate collapsed at the bottom. Bio ≤ 160 chars.

### Out of scope

- Migrating `neuro-spicy-devkit` generator scripts into this repo
- Shipping a fake ETH address or "addresses rotate" fiction
